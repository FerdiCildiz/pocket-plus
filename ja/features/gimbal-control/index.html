ジンバル操作FREE

Pocket を Mac に接続すると macOS はウェブカメラとして認識しますが、動かす手段はありません。Pocket+ がその操作を加えます。カメラに手を伸ばさなくても、画面やキーボードからジンバルの向きとズームを調整できます。

ジョイスティック、中央へ、反転

右下のジョイスティックのつまみをドラッグすれば、すばやく動かせます。矢印をクリックすると 3° ずつ、⌥ を押しながらなら 1° ずつ動きます。矢印を押し続けるとゆっくり動きます。中央へ はカメラを水平にして正面に向け、反転 は画面側と背面側を切り替えます。スムーズな動き がオン（デフォルト）のときは、カメラマンが操作するように動き始めと止まり際がなめらかになります。

ズームとショートカット

− と + のボタン、または ⌘+、⌘− を使い、⌘0 で 1× に戻ります。ズームは段階的に飛ばず、なめらかに変化します。ジンバルは ⌥ と矢印キーで少しずつ動かせます。カメラ本体のズームを使うため、Pocket 3 では 1080p で最大 4×、4K で最大 2× です。ショートカットは Pocket+ がアクティブなアプリのときに使えます。

映像をドラッグして向きを調整

Pro なら、映像をつかんで引っ張ると、カーソルの下の位置を追うようにカメラが向きを変えます。スクロールでズーム、⇧ を押しながらスクロールすると左右に回転します。トラックパッドでは、上下のスワイプでズーム、左右のスワイプで回転します。

ジョイスティック、中央へ、反転、ズームは無料です。映像上でのドラッグとスクロールは Pocket+ Pro の機能です。明るさ、ホワイトバランス、カメラのカラープロファイルは USB 経由では変更できないため、Pocket 本体で設定してください。
