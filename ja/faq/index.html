よくある質問

対応機種、セットアップ、録画、Pro版についての疑問にお答えします。

対応機種・動作環境

対応しているカメラは？

DJI Osmo Pocket 2、3、4、4Pに対応しています。USB-Cで接続し、カメラをウェブカメラモードに設定してください。macOS 15 Sequoia以降を搭載したApple SiliconのMacで利用できます。Intel Macでは未検証です。開発とテストは主にPocket 3で行っています。

Pocket 3をMacのWebカメラとして使えますか？

はい。USB-Cで接続してウェブカメラモードを選び、Pocket+を開いてください。ライブ映像の確認、ジンバル・ズーム操作、顔追跡、Macへの録画ができます。

これは Mac 版の DJI Mimo ですか？

いいえ。DJI Mimo は DJI のスマートフォン用アプリで、Mac 版はありません。Pocket+ は独立した Mac アプリで、USB-C 経由でライブビュー、ジンバルとズームの操作、Mac への直接録画ができます。ファームウェアの更新には、引き続きスマートフォンの Mimo を使ってください。

Pocket+ は DJI と関係がありますか？

いいえ。Pocket+ は独立したプロジェクトであり、DJI とは提携しておらず、DJI による承認や後援を受けたものではありません。

なぜ 4K と 1080p の 30、25、24 fps だけなのですか？

ウェブカメラモードで、USB 経由でカメラが提供しているのがこれらのモードだからです。4K60 と 1080p60 は USB では使えません。

ワイヤレスで使えますか？

まだ使えません。現在、Pocket+ は USB-C ケーブルで動作します。

インストール・アクセス許可

Appleの公証を受けていますか？

はい。Pocket+はApple Developer IDで署名され、Appleの公証を受けています。macOSの追加のセキュリティ警告なしで開けます。ネットワーク通信はアップデートとライセンスの確認に限られます。

なぜカメラ、マイク、Bluetooth へのアクセスを求めるのですか？

カメラとマイクは映像と音声のために使います。Bluetooth は、カメラのバッテリー残量、USB の状態、録画ボタンを読み取るために使います。データが Mac の外に送られることはありません。

アップデートはどのように行われますか？

Pocket+ は1日に1回、新しいバージョンを確認します。新しいバージョンがあれば、「インストールして再起動」をクリックするだけです。確認は「設定 › アップデート」でオフにできます。

カメラ映像が表示されない場合は？

まずウェブカメラモードで接続されているか確認してください。次にPocket+右上の再接続ボタンをクリックします。それでも表示されない場合は、USB-Cケーブルを抜き差ししてください。

ジンバル・顔追跡

顔追跡が自動でオフになるのはなぜですか？

カメラ本体のActiveTrackが有効になっている可能性があります。カメラ側でActiveTrackをオフにすると、Pocket+の顔追跡を使用できます。

顔追跡はカメラの ActiveTrack ですか？

いいえ。Pocket+ は Mac 上で顔を検出し、ジンバルを実際に動かして追いかけます。アプリを開いた時点ではオフで、ジョイスティック下のボタンか ⌘T でオンにできます。無料で使えます。

自動フレーミングとは？

ワンクリックで、映っている人物やグループが収まるように画角とズームを調整し、そこで止まります。顔追跡のようにジンバルが動き続けることはありません。自動フレーミングはProの機能です。

ジンバルの位置を保存できますか？

はい。シーンでは最大 9 か所の位置を保存でき、ワンクリックまたは ⌥1 から ⌥9 で呼び出せます。Pro では、アプリを開いたときにジンバルが前回の位置へ戻る機能も使えます。どちらも Pro の機能です。

ジンバルはどのように操作しますか？

画面上のジョイスティック、矢印キー、ショートカットで操作します。Pro では、映像をドラッグして向きを変えたり、スクロールでズームしたりもできます。

録画・音声

録画はどこに保存されますか？

「ムービー」フォルダに保存されます。別のフォルダは「設定 › 出力フォルダ」で選択できます。

4K で録画できますか？

4K は Pro の機能です。無料版では 1080p まで録画できます。H.264 と HEVC は設定から選べます。

DJI Mic やほかのマイクは使えますか？

はい。カメラとペアリングした DJI Mic は「DJI Mic」と表示されます。Mac に接続した DJI Mic のレシーバーは自動的に選ばれます。マイクメニューから、Mac のどのマイクでも選べます。

LUT は録画にも適用されますか？

お好みで選べます。LUT メニューの「録画に LUT を適用」スイッチで決まり、オフならプレビューだけに LUT がかかります。LUT は Pro の機能です。

Pro版・ライセンス

Pocket+は無料で使えますか？

はい。最大1080pの録画、写真撮影、ジンバル・ズーム操作、顔追跡は無料です。Proでは4K録画、LUT、シーン、自動フレーミングなどが使えます。買い切り39.99米ドル、または年額14.99米ドルから選べます。アカウント登録は不要です。

Pro を有効にするには？

Proを購入すると、ライセンスキーがメールで届きます。それを「設定 › Pro」に貼り付けてください。1つのライセンスで1台のMacでProが有効になります。別のMacで使うには、先に「設定 › Pro」で「このMacから削除」を選んでください。

ほかのアプリとの併用

OBSやGoogle Meetと併用できますか？

はい。OBS、Google Meet、WhatsAppなどでカメラ映像を使っている間も、Pocket+からジンバルとズームを操作できます。ただしLUTや広角補正はPocket+内の表示のみで、これらのアプリには反映されません。仮想カメラはまだありません。
