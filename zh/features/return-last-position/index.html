恢复上次位置PRO

Pocket 每次开机都会自动居中。好不容易调好完美角度时，这就很烦人了。Pocket+ 会记住相机朝向哪里、变焦到多少，并在相机重新连接后立即恢复。

全自动

无需开启任何设置。关机再开机、重新插拔线缆或重启 Pocket+，云台和变焦都会回到你上次的画面。预览顶部会显示一条简短提示，先告诉你正在返回，再告诉你已经回来了。

Pocket+ 会先等待相机自身的开机动作完成，然后直接移到你的画面。如果在此期间你开始自己移动相机，它就交给你来操作。

想重新开始也可以

要清除已存储的位置，请点按标题栏中的复位相机。相机会以 1× 居中，从头开始。横屏和竖屏各自记住自己的上次位置。

恢复上次位置属于 Pocket+ Pro。即使在升级之前，你的位置也会存储在 Mac 上，因此升级后立即生效。分辨率、帧率和编码格式在免费版中同样会被记住。
