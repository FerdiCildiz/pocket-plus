云台控制FREE

把 Pocket 连接到 Mac，macOS 会把它当作网络摄像头，却没有办法转动它。Pocket+ 补上了这些控制：在屏幕上或用键盘调整云台方向和变焦，无需伸手去碰相机。

摇杆、居中和翻转

拖移右下角的摇杆旋钮即可快速移动。点按箭头每次移动 3°，按住 ⌥ 则为 1°。按住箭头可缓慢移动。居中会让相机回到水平并朝向正前方，翻转则让它转向屏幕一侧或背面。开启平滑运动（默认开启）后，移动会像摄像师操作一样缓起缓停。

变焦和快捷键

使用 − 和 + 按钮，或按 ⌘+、⌘−，按 ⌘0 回到 1×。变焦是平滑过渡的，不会跳变。用 ⌥ 加方向键可微调云台。这是相机自身的变焦：在 Pocket 3 上，1080p 最高 4×，4K 最高 2×。快捷键在 Pocket+ 为当前活跃 App 时有效。

拖移画面来调整方向

使用 Pro 时，抓住画面拖动：相机会转动，让光标下的位置跟着移动。滚动即可变焦，按住 ⇧ 滚动则左右转动。在触控板上，上下轻扫变焦，左右轻扫转动。

摇杆、居中、翻转和变焦均免费。在画面上拖移和滚动属于 Pocket+ Pro。亮度、白平衡和相机的色彩配置无法通过 USB 更改，请在 Pocket 上设置。
